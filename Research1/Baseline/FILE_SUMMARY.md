# 对比实验文件清单

## 已创建的文件结构

```
Baseline/
├── README.md                      # 对比实验说明文档
├── compare_models.py              # 统一对比评估脚本（主要）
├── run_experiment.py              # 快速启动脚本
├── visualize_comparison.py        # 详细结果可视化脚本
│
├── VAE/                          # 变分自编码器
│   ├── model_VAE.py              # VAE模型定义（编码器、解码器、重参数化）
│   ├── loss_VAE.py               # VAE损失函数（重构损失、KL散度、频域损失）
│   └── train_VAE.py              # VAE训练脚本
│
├── CVAE/                         # 条件变分自编码器
│   ├── model_CVAE.py             # CVAE模型定义（带标签嵌入的编解码器）
│   └── train_CVAE.py             # CVAE训练脚本
│
├── CycleGAN/                     # 循环一致性GAN
│   ├── model_CycleGAN.py         # CycleGAN模型（双生成器、双判别器、残差块）
│   ├── loss_CycleGAN.py          # CycleGAN损失函数（对抗损失、循环一致性、身份损失）
│   └── train_CycleGAN.py         # CycleGAN训练脚本
│
└── DCGAN/                        # 深度卷积GAN
    ├── model_DCGAN.py            # DCGAN模型（生成器、判别器）
    └── train_DCGAN.py            # DCGAN训练脚本
```

## 文件功能说明

### 主要脚本

1. **compare_models.py** (295行)
   - 统一对比评估所有模型
   - 自动训练5个模型并评估
   - 生成JSON结果和对比图表
   - 输出综合排名表

2. **run_experiment.py** (67行)
   - 快速启动脚本，支持命令行参数
   - 可选择单个模型或全部模型
   - 可自定义训练轮数和样本数

3. **visualize_comparison.py** (221行)
   - 从保存的结果生成详细图表
   - 包括雷达图、排名表、柱状图
   - 自动标注最优模型

### VAE模型文件

4. **model_VAE.py** (146行)
   - VAE编码器：5层卷积 + 全连接
   - VAE解码器：全连接 + 4层转置卷积
   - 重参数化技巧实现
   - 支持从先验分布生成样本

5. **loss_VAE.py** (78行)
   - VAE损失函数（重构损失 + KL散度）
   - 频域损失函数（幅度谱MSE）
   - 组合损失（支持β-VAE和频域权重）

6. **train_VAE.py** (240行)
   - 完整的VAE训练流程
   - 支持目标域数据训练
   - 生成合成样本并评估
   - 保存模型和可视化结果

### CVAE模型文件

7. **model_CVAE.py** (167行)
   - CVAE编码器：标签嵌入 + 卷积网络
   - CVAE解码器：潜在向量+标签融合
   - 支持条件生成（30个类别）

8. **train_CVAE.py** (242行)
   - CVAE训练流程（带标签条件）
   - 条件生成样本
   - 评估和可视化

### CycleGAN模型文件

9. **model_CycleGAN.py** (135行)
   - 生成器：编码器-残差块-解码器
   - 4个残差块增强表达能力
   - PatchGAN判别器
   - 双生成器、双判别器架构

10. **loss_CycleGAN.py** (42行)
    - 对抗损失（MSE Loss）
    - 循环一致性损失（L1 Loss）
    - 身份保持损失（L1 Loss）

11. **train_CycleGAN.py** (286行)
    - 完整的CycleGAN训练循环
    - 源域↔目标域双向转换
    - 循环一致性约束
    - 身份保持训练

### DCGAN模型文件

12. **model_DCGAN.py** (103行)
    - 生成器：全连接 + 4层转置卷积
    - 判别器：4层卷积 + 全连接
    - 经典DCGAN架构

13. **train_DCGAN.py** (253行)
    - DCGAN训练流程
    - BCE损失函数
    - 从随机噪声生成样本

### 2. 公平的对比条件
- 相同的数据集划分
- 相同的训练轮数（50 epochs）
- 相同的生成样本数（900个）
- 相同的随机种子（30）
- 相同的评估指标

- **训练时间**：记录每个模型的训练耗时
- **频谱保真度**：FFT幅度谱的MSE
- **时域MSE**：直接样本对比
- **样本多样性**：标准差比率
- **可视化对比**：多维度图表展示

### 4. 易用的工具链
- 单模型训练：直接运行对应脚本
- 批量对比：一键运行所有模型
- 结果可视化：自动生成详细图表
- 命令行工具：灵活配置参数

## 使用流程

### 快速开始（3步）

```bash
# 步骤1：运行完整对比实验
python Baseline/compare_models.py

# 步骤2：等待所有模型训练完成（可能需要数小时）

# 步骤3：查看结果
python Baseline/visualize_comparison.py
```
