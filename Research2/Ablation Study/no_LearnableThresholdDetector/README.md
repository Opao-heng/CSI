# 消融实验：仅使用传统OpenMax组件

## 实验目的

本消融实验旨在评估可学习阈值检测器在入侵者检测模型中的贡献。通过去除可学习的神经网络检测模块，仅保留传统的基于极值理论的OpenMax组件，来验证可学习组件对整体性能的影响。

## 实验设计

### 模型结构修改

1. **去除可学习组件**：
   - 移除了可学习的阈值检测器
   - 移除了特征融合层中的可学习部分
   - 仅保留传统的OpenMax模块

2. **简化检测流程**：
   - 直接使用传统OpenMax进行入侵者检测
   - 不再使用神经网络进行特征融合

### 模型组件

- `TraditionalOpenMax`: 传统的基于极值理论的OpenMax检测器
- `TraditionalIntruderDetectorOnly`: 主检测模型，仅包含传统组件

## 实验流程

1. 使用已训练的无对比损失身份识别模型（来自 `no_contrastive` 实验）提取特征
2. 使用传统OpenMax组件进行入侵者检测
3. 在测试集上评估入侵者检测性能

## 预期结果

- 性能应低于完整模型，但高于随机猜测
- 验证可学习组件在入侵者检测中的价值
