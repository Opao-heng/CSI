# 消融实验：去除传统OpenMax组件

## 实验目的

本消融实验旨在评估传统OpenMax组件在入侵者检测模型中的贡献。通过去除传统的基于极值理论的OpenMax组件，仅保留可学习的神经网络检测模块，来验证传统组件对整体性能的影响。

## 实验设计

### 模型结构修改

1. **去除传统OpenMax组件**：
   - 移除了基于极值理论的传统OpenMax模块
   - 仅保留可学习的阈值检测器和特征融合层

2. **简化融合策略**：
   - 不再使用传统OpenMax的概率输出
   - 仅使用身份识别模型提取的特征和logits作为输入

### 模型组件

- `LearnableThresholdDetector`: 可学习的阈值检测器，用于处理输入特征
- `LearnableIntruderDetectorNoTraditional`: 主检测模型，仅包含可学习组件

## 实验流程

1. 使用已训练的无对比损失身份识别模型（来自 `no_contrastive` 实验）提取特征
2. 重新训练仅包含可学习组件的入侵者检测器
3. 在测试集上评估入侵者检测性能

## 预期结果

- 性能应低于完整模型，但高于随机猜测
- 验证传统OpenMax组件在入侵者检测中的价值
