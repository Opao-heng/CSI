# 入侵者检测模块

## 概述

本模块实现了基于WiFi CSI数据的身份认证和入侵者检测系统，解决室内环境中跨域适应性和开放集识别两个关键挑战。

## 功能特性

1. **深度学习模型架构**: 实现了研究内容二要求的四阶段模型架构
2. **特征提取器**: 带注意力机制的特征提取器，处理CSI时序数据
3. **对比域适应模块**: 通过对比学习减小源域和目标域的分布差异
4. **身份分类器**: 对已知用户进行精确的身份识别
5. **开放集检测模块**: 双重机制（OpenMax + 能量检测）识别入侵者

## 系统架构

```
IntruderDetectionSystem
├── FeatureExtractor              # 特征提取器
├── AttentionModule               # 注意力模块
├── ContrastiveDomainAdapter      # 对比域适应模块
├── IdentityClassifier            # 身份分类器
├── OpenMaxIntruderDetector       # OpenMax入侵者检测器
├── EnergyIntruderDetector        # 能量入侵者检测器
└── ComprehensiveIntruderDetector # 综合入侵者检测器
```

## 数据集划分

根据研究内容二的要求，数据集划分为：

1. **源域训练集**: env0 和 env1 中 10 名已知用户的 CSI 数据
2. **目标域辅助集**: env2 中 10 名已知用户的少量数据（用于域适应）
3. **验证集**: 从目标域辅助集中划分部分数据，并加入少量模拟入侵者数据（用于阈值确定）
4. **测试集**: env2 中 10 名已知用户（300 样本）和 3 名入侵者（90 样本）的混合数据

## 模型架构设计

### 1. 带注意力的特征提取器
- 输入：CSI 数据（形状为 [batch_size, 56, 3, 6000]）
- 输出：128 维的判别性特征向量
- 结构：1D卷积处理时间维度 + 2D卷积处理子载波维度 + 注意力机制增强特征

### 2. 对比域适应模块
- 作用：减小源域和目标域的分布差异
- 原理：通过对比学习，拉近相同用户在不同域的特征距离
- 实现：
  - 投影头：将特征映射到 32 维空间
  - 对比损失：最大化同类样本相似度，最小化不同类样本相似度

### 3. 身份分类器
- 作用：对已知用户进行身份识别
- 结果：输出 10 维 logits（对应 10 名已知用户）

### 4. 开放集检测模块
- 作用：区分已知用户和入侵者
- 双重机制：
  - OpenMax：基于 Weibull 分布建模已知用户的特征分布
  - 能量检测：计算模型对所有已知类别的总置信度（能量越低越可能是入侵者）
- 决策融合：结合两种机制的结果，提高检测可靠性

## 入侵者检测机制详解

### OpenMax入侵者检测器
- 基于极值理论（EVT）建模已知用户特征分布
- 为每个已知用户类别拟合Weibull分布
- 通过距离排名机制计算未知类别概率
- 当未知概率超过阈值时判定为入侵者

### 能量入侵者检测器
- 基于模型输出的概率分布计算能量分数（负熵）
- 能量分数越高表示模型越不确定，越可能是入侵者
- 当能量分数超过阈值时判定为入侵者

### 综合入侵者检测器
- 融合OpenMax和能量检测两种机制
- 采用"或"决策策略：任一检测器判定为入侵者即为入侵者
- 提供更可靠的入侵者检测性能

## 训练流程

训练分为三个阶段，逐步优化模型性能：

### 1. 预训练阶段
- 仅使用源域数据训练特征提取器和身份分类器
- 优化目标：最小化交叉熵损失，确保在源域上有良好的身份识别性能

### 2. 域适应阶段
- 联合使用源域数据和目标域已知用户数据
- 优化目标：
  - 身份分类损失（保持类别判别性）
  - 对比域适应损失（减小域差异）
- 训练策略：交替更新特征提取器和对比适应模块

### 3. 开放集参数拟合阶段
- 使用验证集数据拟合 OpenMax 所需的 Weibull 分布参数
- 在验证集上搜索最佳决策阈值（能量阈值和概率阈值）

## 核心组件

### FeatureExtractor
- 处理CSI时序数据，提取128维判别性特征
- 使用1D和2D卷积处理时间和空间维度
- 集成注意力机制增强特征表示

### AttentionModule
- 应用自注意力机制增强特征表示
- 通过残差连接保持信息完整性

### ContrastiveDomainAdapter
- 通过对比学习实现域适应
- 投影头将特征映射到32维空间进行对比

### IdentityClassifier
- 对已知用户进行身份识别
- 输出各类别概率分布

### OpenMaxIntruderDetector
- 基于极值理论建模已知用户特征分布
- 使用Weibull分布拟合每个类别的特征距离
- 通过未知概率检测入侵者

### EnergyIntruderDetector
- 计算模型对输入样本的总置信度（能量分数）
- 通过负熵计算能量分数
- 基于能量阈值检测入侵者

### ComprehensiveIntruderDetector
- 融合OpenMax和能量检测两种机制
- 提供更可靠的入侵者检测性能
- 支持参数调优和阈值设置

### IntruderIdentificationSystem
- 完整的入侵者识别系统
- 集成检测和识别功能
- 提供端到端的解决方案

## 性能指标

### 入侵者检测性能
- 检测准确率：正确检测的入侵者和已知用户占总样本的比例
- F1分数：平衡精确率和召回率，适合不平衡数据

### 身份识别性能
- 识别准确率：正确识别的已知用户占所有已知用户样本的比例
- 宏平均F1分数：评估对不同用户的识别稳定性

## 训练细节

### 损失函数
- 身份分类损失：交叉熵损失
- 域适应损失：MMD距离最小化
- 对比损失：同类样本相似度最大化

### 优化器
- Adam优化器，学习率0.001
- 学习率调度器：每30个epoch衰减0.1倍

### 训练参数
- batch_size: 32
- epochs: 100
- 损失权重：
  - 身份分类损失: 1.0
  - 域适应损失: 0.5
  - 对比损失: 0.3
