## 技术栈概述

本项目构建于Python生态系统之上，采用了一系列先进的技术栈来实现CSI（信道状态信息）数据的处理、分析和深度学习建模。项目技术栈主要由深度学习框架、数值计算库、文件处理库、可视化工具和信号处理库组成，形成了一个完整的数据科学工作流。

项目架构分为三个主要模块：预处理模块（pre_process）、注意力机制模块（Attention）和生成对抗网络模块（GAN）。预处理模块负责数据加载、去噪和增强；注意力机制模块实现跨域特征提取和分类；GAN模块则用于生成符合目标域分布的虚假样本。这些模块协同工作，共同完成CSI数据的深度分析和身份识别任务。

## 核心依赖库详解

### PyTorch深度学习框架

PyTorch是本项目的核心深度学习框架，贯穿于模型定义、训练和推理的全过程。项目中的注意力机制和GAN模型均基于PyTorch的`nn.Module`类构建，充分利用了其动态计算图和自动微分特性。

在`attention.py`文件中，`FeatureExtractor`类使用`nn.Sequential`构建了卷积神经网络，通过1D和2D卷积层处理CSI数据的多维特征。`MultiHeadAttention`类实现了多头注意力机制，用于捕捉源域和目标域之间的复杂关系。在`GAN/model.py`中，`FeatureExtractor`、`Generator`和`Discriminator`三个类共同构成了生成对抗网络架构，其中生成器采用U-Net结构，判别器采用卷积神经网络。

PyTorch还提供了数据加载和处理功能，在`dataloder_ATT.py`中使用`torch.utils.data.Dataset`和`DataLoader`类实现了高效的数据批处理机制，支持数据的并行加载和随机打乱。

### NumPy数值计算库

NumPy作为Python科学计算的基础库，在项目中扮演着关键角色。它提供了高效的多维数组对象和丰富的数学函数，是数据处理和数值计算的基石。

在`preprocess.py`文件中，NumPy与PyTorch紧密配合，特别是在小波变换去噪过程中。`dwt_denoise_csi`函数首先将PyTorch张量转换为NumPy数组（使用`.numpy()`方法），然后利用`pywt`库进行小波变换，其中`np.std()`和`np.sqrt()`等NumPy函数用于计算去噪阈值。在`data.py`文件中，`group_amp_data`函数使用`np.array()`和`np.transpose()`对CSI幅度数据进行分组和维度变换，确保数据格式符合后续处理要求。

### h5py用于HDF5文件读取

h5py库专门用于读取和写入HDF5格式的文件，是项目中数据输入的关键组件。HDF5是一种高效的科学数据格式，特别适合存储大规模的多维数组数据，如本项目中的CSI数据。

在`pre_process/data.py`文件中，`load_mat_data`函数使用`h5py.File`上下文管理器打开v7.3格式的.mat文件（MATLAB的HDF5格式），并从中提取`amp`（幅度）、`id`（身份标识）和`env`（环境）三个数据组。这种方法避免了传统MAT文件加载器的兼容性问题，能够高效地处理大型数据集。`with h5py.File(file_path, 'r') as f:`语句确保了文件资源的正确管理，即使在读取过程中发生异常也能安全关闭文件。

### matplotlib用于结果可视化

matplotlib是Python中最流行的2D绘图库，用于创建高质量的科学图表。在项目中，它主要用于CSI数据的可视化分析，帮助研究人员理解数据特征和模型输出。

`pre_process/CSI_fig.py`文件展示了matplotlib的典型用法。该脚本加载预处理后的CSI数据，选择特定样本，绘制不同天线维度的幅度随时间变化的曲线图。代码使用`plt.subplots`创建多子图布局，`plt.plot`绘制时间序列，`plt.style.use('seaborn-v0_8')`应用美观的样式，`plt.tight_layout`自动调整子图间距。通过为不同天线分配不同的颜色（`plt.cm.Set1`），生成的图表清晰地展示了CSI信号的多维特性，便于进行数据质量检查和特征分析。

### pywt用于小波变换

pywt（PyWavelets）是一个专门用于小波分析的Python库，在项目中用于CSI数据的去噪处理。小波变换能够同时提供信号的时域和频域信息，非常适合处理非平稳信号，如CSI数据。

`pre_process/preprocess.py`文件中的`dwt_denoise_csi`函数是pywt的核心应用场景。该函数对CSI幅度数据的每个子载波进行离散小波变换（DWT），使用`pywt.wavedec`分解信号，然后应用软阈值去噪（`pywt.threshold`），最后通过`pywt.waverec`重构去噪后的信号。去噪阈值采用通用阈值公式`σ√(2logN)`，其中σ是小波系数的标准差，N是信号长度。这种方法能有效去除CSI数据中的随机噪声，同时保留重要的步态特征，为后续的机器学习任务提供更干净的输入。

## 环境配置指南

### Python包安装

由于项目中未提供`requirements.txt`或`environment.yml`文件，建议用户根据上述技术栈分析手动创建环境配置文件。以下是推荐的`requirements.txt`内容：

```txt
torch>=1.9.0
torchvision>=0.10.0
torchaudio>=0.9.0
numpy>=1.19.0
h5py>=3.1.0
matplotlib>=3.3.0
PyWavelets>=1.1.0
```

用户可以通过以下命令安装所有依赖：

```bash
pip install -r requirements.txt
```

对于使用conda的用户，可以创建一个`environment.yml`文件：

```yaml
name: csi-analysis
channels:
  - pytorch
  - conda-forge
  - defaults
dependencies:
  - python=3.8
  - pytorch
  - torchvision
  - torchaudio
  - numpy
  - h5py
  - matplotlib
  - pywavelets
  - pip
```

然后使用`conda env create -f environment.yml`命令创建环境。

### 版本兼容性注意事项

在配置环境时，需要注意以下版本兼容性问题：

1. **PyTorch与CUDA版本匹配**：如果使用GPU，必须确保PyTorch版本与系统安装的CUDA版本兼容。例如，PyTorch 1.9.0通常与CUDA 11.1或11.3兼容。
2. **h5py与HDF5库**：h5py需要系统底层的HDF5库支持。在某些Linux发行版上，可能需要先安装`libhdf5-dev`包。
3. **matplotlib后端**：在无GUI的服务器环境中，可能需要设置非交互式后端，如`Agg`，以避免绘图错误。

## 可复现的环境设置脚本

为了确保环境的可复现性，建议使用以下脚本进行环境配置：

```bash
#!/bin/bash
# setup_environment.sh

# 检查Python版本
PYTHON_VERSION=$(python --version 2>&1 | awk '{print $2}')
if [[ "$PYTHON_VERSION" < "3.8" ]]; then
    echo "错误：需要Python 3.8或更高版本"
    exit 1
fi

# 创建虚拟环境
python -m venv csi_env
source csi_env/bin/activate

# 升级pip
pip install --upgrade pip

# 安装依赖
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
pip install numpy h5py matplotlib PyWavelets

# 验证安装
python -c "import torch; print(f'PyTorch版本: {torch.__version__}'); print(f'GPU可用: {torch.cuda.is_available()}')"
python -c "import numpy as np; print(f'NumPy版本: {np.__version__}')"
python -c "import h5py; print(f'h5py版本: {h5py.__version__}')"
python -c "import matplotlib; print(f'matplotlib版本: {matplotlib.__version__}')"
python -c "import pywt; print(f'pywt版本: {pywt.__version__}')"

echo "环境配置完成！"
```

## 操作系统特定安装建议

### Windows系统

在Windows系统上安装时，建议使用Anaconda或Miniconda作为Python发行版，因为它能更好地管理复杂的科学计算包依赖。对于PyTorch的GPU版本，需要确保已安装NVIDIA显卡驱动和CUDA Toolkit。

如果遇到h5py安装问题，可以尝试使用预编译的wheel包：
```bash
pip install --only-binary=h5py h5py
```

### Linux系统

在Linux系统上，特别是Ubuntu/Debian发行版，建议先安装系统级依赖：
```bash
sudo apt-get update
sudo apt-get install libhdf5-dev libhdf5-serial-dev libhdf5-103
sudo apt-get install libatlas-base-dev libopenblas-dev liblapack-dev
```

然后使用pip安装Python包。对于CentOS/RHEL系统，使用相应的`yum`或`dnf`命令。

## GPU加速配置

为了提升训练效率，强烈建议配置GPU加速。以下是详细的配置步骤：

### CUDA和cuDNN安装

1. **检查GPU兼容性**：确保显卡支持CUDA，可在NVIDIA官网查询。
2. **安装CUDA Toolkit**：从NVIDIA官网下载与显卡驱动兼容的CUDA版本。
3. **安装cuDNN**：注册NVIDIA开发者账号后下载cuDNN，并将其文件复制到CUDA安装目录。

### PyTorch GPU版本安装

使用以下命令安装支持CUDA的PyTorch：
```bash
# 对于CUDA 11.8
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 对于CUDA 12.1
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 验证GPU配置

安装完成后，运行以下Python代码验证GPU是否可用：
```python
import torch
print(f"PyTorch版本: {torch.__version__}")
print(f"CUDA可用: {torch.cuda.is_available()}")
if torch.cuda.is_available():
    print(f"GPU数量: {torch.cuda.device_count()}")
    print(f"当前GPU: {torch.cuda.current_device()}")
    print(f"GPU名称: {torch.cuda.get_device_name(0)}")
```

正确配置后，可以在模型和数据上使用`.cuda()`或`.to('cuda')`方法将计算迁移到GPU，显著加速训练过程。
