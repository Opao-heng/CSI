## 数据预处理

本节演示如何从原始 `.mat` 或 `.npy` 文件加载 CSI 数据，并通过 `preprocess.py` 中的函数完成归一化、去噪、分割和数据增强。

### 加载原始数据

首先，使用 `SourceData.py` 和 `TargetData.py` 提供的工具加载原始数据。这些脚本支持从多个环境（如 `env0`, `env1`）加载 `.npy` 或 `.npz` 格式的数据文件，并自动提取用户 ID 作为标签。

```python
from pre_process.SourceData import load_combined_env_data
from pre_process.TargetData import load_env_data

# 加载源域数据（env0 和 env1）
source_data, source_labels = load_combined_env_data("../data/env0", "../data/env1")

# 加载目标域数据（env2）
target_data, target_labels = load_env_data("../data/env2")
```

**预期输出：**
```
加载env0数据...
处理文件: id_0_env_0.npy, id: 0, 样本数: 100
...

总样本数: 2000
数据形状: torch.Size([2000, 56, 3, 6000])
标签形状: torch.Size([2000])
```

### 执行完整预处理流程

调用 `preprocess_csi_data` 函数执行完整的预处理流程：

```python
from pre_process.preprocess import preprocess_csi_data

# 假设 csi_amplitude 是从 .npy 文件加载的原始幅度数据
# 形状应为 (num_persons, num_samples, num_tx_rx, num_time, num_subcarriers)
augmented_data, augmented_labels = preprocess_csi_data(csi_amplitude)
```

该函数依次执行以下步骤：
1. **归一化**：对每个子载波的时间序列进行均值-标准差归一化。
2. **DWT 去噪**：使用离散小波变换（默认 `db4` 小波，4 层）去除噪声。
3. **步态分割**：将时间维度统一为 6000 点，不足则填充，超出则截取中间部分。
4. **数据增强**：通过添加高斯噪声、模拟多径衰落和频率选择性衰落生成三倍增强数据。

**预期输出：**
```
开始CSI数据预处理...
1. 执行归一化...
2. 执行DWT去噪...
3. 执行步态分割...
4. 执行数据增强...
预处理完成!
原始数据形状: torch.Size([10, 56, 3, 6000, 56])
增强后数据形状: torch.Size([10, 224, 3, 6000, 56])
```

### 常见错误提示

- **`ValueError: Expected 4D input`**：确保输入张量为 4D `(batch, 56, 3, 6000)`，若为 5D 需先合并前两维。
- **`AssertionError: 数据第0维应该是56`**：检查原始 `.npy` 文件是否正确，CSI 子载波数必须为 56。
- **内存不足**：若数据量过大，建议分批次处理或使用 `DataLoader`。

## 模型训练

本节展示如何配置并运行 Attention 或 GAN 模型的训练脚本。

### 训练 Attention 模型

Attention 模型通过交叉注意力机制实现跨域身份识别。训练脚本位于 `Attention/train.py`。

```python
# train_identify.py 已包含完整训练逻辑，直接运行即可
python Attention/train.py
```

**关键参数配置：**
- `num_classes=10`：分类类别数（用户数）。
- `alpha=1.0, beta=1.0`：源域和目标域分类损失权重。
- `gamma=0.3, delta=0.2`：跨域特征和一致性损失权重。
- `lr=3e-4`：使用 AdamW 优化器，学习率 0.0003。
- `num_epochs=100`：最大训练轮数，支持早停（patience=15）。

**数据加载器配置：**
`dataloder_ATT.py` 自动加载预处理后的 `source_data.pt` 和 `target_data.pt`，并创建 `DataLoader`。

### 训练 GAN 模型

GAN 模型用于生成符合目标域分布的虚假样本，以扩充数据。

```python
# 运行 GAN 训练
python GAN/train.py
```

**模型组件：**
- `FeatureExtractor (E)`：提取目标域环境特征。
- `Generator (G)`：融合源域身份与目标域环境生成虚假数据。
- `Discriminator (D)`：判别真实与虚假目标域数据。

**训练流程：**
1. 提取目标域特征 `f_t`。
2. 交替训练判别器 `D` 和生成器 `G`。
3. 生成 900 个虚假样本并与原始目标域数据合并，保存至 `../data/TargetData_hat/`。

**关键参数：**
- `lambda_E=0.5, lambda_feat=1.0`：特征提取与匹配损失权重。
- `epochs=20`：训练轮数。
- `lr=0.001`：学习率。

**预期输出：**
```

  Train Loss: 1.2345
...
Model saved at best_model.pth
Generating synthetic samples for data augmentation...

```

## 身份识别

本节演示如何加载训练好的模型，对新采集的 CSI 数据进行特征提取和分类预测。

### 加载训练好的模型

```python
import torch
from Research1.model_ATT import CrossAttentionModel

# 加载最佳模型
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = CrossAttentionModel(num_classes=10).to(device)
checkpoint = torch.load("models/best_cross_attention_model.pth", map_location=device)
model.load_state_dict(checkpoint['model_state_dict'])
model.eval()
```

### 预处理新数据

对新采集的 CSI 数据执行与训练时相同的预处理流程：

```python
from pre_process.preprocess import preprocess_csi_data
import torch

# 假设 new_csi_data 是新采集的原始数据，形状为 (1, 56, 3, 6000)
# 注意：需要扩展维度以匹配批处理要求
csi_amplitude = torch.tensor(new_csi_data).unsqueeze(0)  # -> (1, 1, 56, 3, 6000)

# 由于 preprocess_csi_data 期望 (num_persons, num_samples, ...)，
# 这里我们将其视为单个样本的单个人
csi_amplitude = csi_amplitude.squeeze(1)  # -> (1, 56, 3, 6000)

# 执行预处理（仅归一化、去噪、分割，无需增强）
# 我们可以调用单个函数或修改 preprocess_csi_data
from pre_process.preprocess import normalize_csi_data, dwt_denoise_csi, extract_gait_segment

normalized = normalize_csi_data(csi_amplitude)
denoised = dwt_denoise_csi(normalized)
segmented = extract_gait_segment(denoised)  # 输出形状: (1, 56, 3, 6000)
```

### 执行分类预测

```python
with torch.no_grad():
    # 注意：Research1 模型需要源域和目标域数据
    # 在推理时，我们可以将预处理后的数据同时作为源域和目标域输入
    src_data = segmented.to(device)
    tgt_data = segmented.to(device)
    
    pred_s, pred_t, _, _, _ = model(src_data, tgt_data)
    
    # 使用目标域预测结果
    pred_t_prob = torch.softmax(pred_t, dim=1)
    confidence, predicted_label = torch.max(pred_t_prob, 1)

print(f"预测身份: {predicted_label.item()}")
print(f"置信度: {confidence.item():.4f}")
```

**预期输出：**
```
预测身份: 7
置信度: 0.9876
```

### 常见错误提示

- **`RuntimeError: Input shape mismatch`**：确保输入张量形状为 `(batch, 56, 3, 6000)`，与模型期望一致。
- **`KeyError: 'model_state_dict'`**：检查模型文件是否完整，确保保存了 `state_dict`。
- **低置信度预测**：可能是新数据与训练域差异过大，建议检查预处理流程或重新校准模型。

## 模块接口约定

为确保各模块协同工作，必须遵守以下接口约定：

### 数据张量形状要求

| 模块 | 输入形状 | 说明 |
|------|---------|------|
| `preprocess.py` | `(N, 56, 3, 6000)` | `N` 为样本数，56 子载波，3 天线对，6000 时间点 |
| `FeatureExtractor` (Attention) | `(B, 56, 3, 6000)` | 批次大小 `B`，其余同上 |
| `FeatureExtractor` (GAN) | `(B, 3, 56, 6000)` | 注意天线与子载波维度顺序 |
| `Generator` (GAN) | 源域 `(B, 3, 56, 6000)` + 目标域特征 `(M, 128)` | 生成虚假目标域数据 |

### 数据类型与设备

- 所有数据应为 `torch.Tensor` 类型，`dtype=torch.float32`。
- 标签为 `torch.LongTensor`。
- 训练和推理时需确保模型与数据在同一设备（CPU/GPU）。

### 文件命名与路径

- 原始数据文件名格式：`id_{user_id}_env_{env_id}.npy`
- 预处理后数据保存路径：
  - 源域：`../data/SourceData/source_data.pt`, `source_labels.pt`
  - 目标域：`../data/TargetData/target_data.pt`, `target_labels.pt`
  - GAN 增强后目标域：`../data/TargetData_hat/target_data.pt`
